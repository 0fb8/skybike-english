# 単語のレベル表（CEFR）

例文の単語のレベルを判定する（`npm run content:levels`）ための単語表です。どちらも配布元のファイルをそのまま置いています。

| ファイル | 内容 | 権利・ライセンス |
| --- | --- | --- |
| `cefrj-vocabulary-profile-1.5.csv` | CEFR-J Wordlist（A1〜B2、約 7,800 語） | © 東京外国語大学 投野由紀夫研究室。研究・商用とも無償で利用可（出典の明記が条件） |
| `octanove-vocabulary-profile-c1c2-1.0.csv` | Octanove Vocabulary Profile C1/C2（C1〜C2、約 2,100 語） | Octanove Labs。[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |

入手元: https://github.com/openlanguageprofiles/olp-en-cefrj （Open Language Profiles）
